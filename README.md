# RommeApp
Rommé App
Diese App ist ein kleines Projekt, das mit KI erstellt wurde.
Es gibt zwei Ligen: 
- Die Gabelmann-Liga
- Die Walter-Liga

Die Ligen haben leicht unterschiedliche Bedingungen.
Außerdem gibt es getrennte Zugangsberechtigungen.

Es wird eine kostenlose Version von Supabase verwendet. Das entsprechend Supabase-Projekt muss man leider öfter reaktivieren, weil Supabase seine Projekte dauernd scant und nicht verwendete Projekte runterfährt.
